# 🧠 Guia do Mentor e Revisor Técnico — MentoraHub

Este guia destina-se a mentores seniores, engenheiros de software voluntários, professores revisores e alunos veteranos integrantes da **Trilha Conselho**.

---

## 🎯 O Papel da Mentoria Socioeducativa

O objetivo do *Code Review* (revisão de código) no MentoraHub não é apenas garantir a qualidade do software, mas **ensinar e encorajar**. Cada revisão deve ser encarada como um momento pedagógico de fortalecimento da autonomia do estudante.

---

## 📐 Diretrizes de Comunicação e Tom de Voz

1. **Empatia Técnica:** Lembre-se de que muitos contribuidores estão enviando o seu primeiro *Pull Request* da vida.
2. **Elogie Antes de Corrigir:** Identifique pontos positivos antes de apontar melhorias.
3. **Explique o 'Porquê', Não Apenas o 'O Quê':** Em vez de dizer *"Mude a linha 12"*, diga *"Que tal usarmos a tag `<button>` na linha 12? Isso permite que leitores de tela para pessoas com deficiência visual identifiquem o botão corretamente."*

---

## 🔍 Checklist de Validação de um Pull Request (PR)

Antes de aprovar e realizar o *Merge* (incorporação) de um código no site oficial, verifique:

- [ ] **Aderência ao Desafio:** O código atende a todos os *Critérios de Aceitação* descritos na Issue relacionada?
- [ ] **Segurança e Privacidade:** O Pull Request não contém chaves de API, senhas, dados pessoais ou arquivos temporários do sistema?
- [ ] **Acessibilidade Básica:** As imagens possuem atributo `alt` e os links/botões funcionam via navegação por teclado?
- [ ] **Responsividade:** O layout visual funciona adequadamente em telas de celular e desktop?

---

## 🛠️ Passo a Passo para Aprovar uma Contribuição pelo Navegador

1. Acesse a aba [Pull Requests](https://github.com/rodrigojramosDev/mentorahub/pulls).
2. Clique no PR que deseja revisar.
3. Clique na aba **Files changed** para examinar o que foi alterado no código.
4. Se houver algo a corrigir, deixe um comentário educado sugerindo a melhoria.
5. Se estiver tudo correto, volte à aba **Conversation**, role até o final e clique no botão verde **Merge pull request** e depois em **Confirm merge**.
6. Deixe uma mensagem de parabéns ao contribuidor!
